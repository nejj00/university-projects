# My University Projects

## Information Retrieval and Search Engines

### [RAG System](https://github.com/nejj00/uni-rag-project)

A two-part Retrieval-Augmented Generation system built for the *Information Retrieval & Search Engines* course. Part 1 implements a RAG pipeline from scratch over a recipe dataset using classical TF-IDF retrieval; Part 2 extends it with dense embeddings, long-document handling, and query augmentation over a corpus of ACL Anthology papers.

## Big Data Analytics Programming

### [Online Naive Bayes Spam Filter](https://github.com/nejj00/ku-leuven-bdap-assignment-1)

Implemented a Naive Bayes spam filter in C++ that can deal with infinite examples and features. Two techniques were used to deal with infinite and unknown features - feature hashing and count-min sketch. After implementation the techniques were benchmarked with custom experiments and a final report about the results and takeaways was written.
